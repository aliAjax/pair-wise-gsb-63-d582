# 游乐设施日常检验与缺陷闭环平台

基于Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket和Vite的独立前端工程。数据默认保存在localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 检验员/值班负责人分权编辑：检验员仅改实测值与备注，负责人仅改风险、责任人与截止日期。
- 保存按进入编辑时的版本做乐观并发检查，后到者保留自己的填写并列出冲突字段，双方内容自动合并。
- 检验项、记录版本与操作审计作为同一次提交落库；写入失败自动恢复上次完整版本，重试按事务号幂等，不重复生成审计。
- 复测依赖的读数变更时，未确认复测与关闭结论失效重算；已关闭记录保留原关闭依据并列出需复核项。
- 缺陷处置泳道、风险排序、责任人调整和资源冲突提示。
- 状态流转校验、停用隔离、复测与闭环审计。
- JSON记录导出、版本号和完整操作时间线。

## 启动

```bash
npm install
npm run dev
```

访问`http://localhost:18463`。
